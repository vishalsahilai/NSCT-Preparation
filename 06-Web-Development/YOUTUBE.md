# YouTube Learning Resources: Web Development

This page provides beginner-friendly resources for understanding the foundations of web development.

Start with HTML and CSS, then move to JavaScript.

## Recommended videos

### 1. HTML and CSS Full Course: SuperSimpleDev

**Video:** [Watch on YouTube](https://www.youtube.com/watch?v=G3e-cpL7ofc)

- **Level:** Beginner
- **Focus:** HTML and CSS fundamentals.
- **What you will learn:**
  - Structure of web pages.
  - HTML elements.
  - Headings, paragraphs and links.
  - Images and forms.
  - CSS selectors.
  - Colours, spacing and layouts.
  - Basic responsive design concepts.

**How to use it:**

Start with HTML and understand how a webpage is structured.

Then learn CSS to understand how that structure is styled.

### 2. JavaScript Full Course

**Video:** [Watch on YouTube](https://www.youtube.com/watch?v=EerdGm-ehJQ)

- **Level:** Beginner
- **Focus:** JavaScript programming fundamentals.
- **What you will learn:**
  - JavaScript basics.
  - Variables and data types.
  - Operators.
  - Conditions and loops.
  - Functions.
  - Arrays and objects.
  - Basic programming logic.

**How to use it:**

Watch JavaScript after understanding the basics of HTML and CSS.

Practise writing small programs and understand how JavaScript adds behaviour to web pages.

## Topics to practise after watching

Follow the Web Development `topics.md` checklist.

Common areas include:

- HTML.
- CSS.
- JavaScript.
- Web page structure.
- Forms and input elements.
- Client-side scripting.
- Frontend and backend concepts.
- HTTP and HTTPS.
- Web browsers and web servers.
- Responsive web design.

## Practice method

Build a small webpage while learning.

For example:

1. Create a basic HTML page.
2. Add headings and paragraphs.
3. Add images and links.
4. Style the page with CSS.
5. Add simple JavaScript behaviour.
6. Review the concepts using MCQs.

## Coverage note

The first video focuses on HTML and CSS. The second focuses on JavaScript.

Together, they provide a useful introduction but do not necessarily cover backend development, databases, web security, APIs or deployment.

Use the repository's checklist to identify additional topics.
