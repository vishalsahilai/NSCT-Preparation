
# NSCT Preparation 🇵🇰

A free, community-driven preparation repository for Pakistan's **National Skills Competency Test (NSCT)** for IT graduates.

This repository is designed to help students prepare systematically through subject-wise study materials, topic checklists, notes, YouTube tutorials, practice questions, revision sheets, and mock tests.

Whether you are starting from zero or revising your university concepts, this repository provides a structured path for your NSCT preparation.

---

## 🎯 What You'll Find in This Repository

- 📚 Subject-wise preparation materials
- 📝 Detailed topic checklists
- 💻 Programming and problem-solving practice
- 🎥 Curated YouTube learning resources for every subject
- 📖 Study notes and revision sheets
- 🧪 Mock tests and practice material
- 📊 Progress tracking
- 🗺️ A structured preparation roadmap

---

## 🚀 Getting Started

New to NSCT preparation? Follow these steps:

1. Read the [Getting Started Guide](00-Getting-Started/START-HERE.md).
2. Review the [NSCT Exam Guide](00-Getting-Started/EXAM-GUIDE.md).
3. Check the [Official NSCT Portal](https://nsct.hec.gov.pk/).
4. Follow the [Preparation Roadmap](ROADMAP.md).
5. Read the [Study Strategy](STUDY-STRATEGY.md).
6. Start studying each subject using its topic checklist and YouTube resources.
7. Track your progress using the [Progress Tracker](PROGRESS-TRACKER.md).

## 📖 Recommended Study Approach

For each subject, follow this simple learning cycle:

1. **Understand:** Read the topic and learn its basic concepts.
2. **Watch:** Use the recommended YouTube tutorials.
3. **Practice:** Solve relevant questions and exercises.
4. **Revise:** Review your notes and revision sheet.
5. **Track:** Update your progress tracker.

Do not focus only on watching videos. Practice and revision are equally important.
