# NSCT Preparation

An unofficial, community-built study repository for Pakistan's **National Skills Competency Test (NSCT)** for IT graduates.

## Start here
1. Read [START-HERE](00-Getting-Started/START-HERE.md).
2. Review the official [HEC competency areas and weightage](https://nsct.hec.gov.pk/AreasOfCompetencies).
3. Use each subject's `topics.md` as the detailed study checklist.
4. Use `resources/youtube-resources.md` for the video list you supplied.
5. Track progress in [PROGRESS-TRACKER](PROGRESS-TRACKER.md).

## Important
The detailed subtopic breakdowns in this repository expand the headings published by HEC into a practical study checklist. They are study guidance, not a claim that HEC publishes every subtopic at this level. Check the official portal for current instructions, dates and candidate information. This is **NSCT**, not NUST NET.
