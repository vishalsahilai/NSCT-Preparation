# YouTube Learning Resources: Databases

This page provides video resources for learning database fundamentals, SQL and related concepts.

Start with basic database terminology before moving to complex queries.

## Recommended videos

### 1. SQL and Database Design Course

**Video:** [Watch on YouTube](https://www.youtube.com/watch?v=HXV3zeQKqGY)

- **Level:** Beginner to Intermediate
- **Focus:** SQL and relational database fundamentals.
- **What you will learn:**
  - Introduction to databases.
  - Relational database concepts.
  - Tables, rows and columns.
  - SQL queries.
  - Filtering and sorting data.
  - Joins.
  - Database design fundamentals.

**How to use it:**

Watch the introduction first.

Practise each SQL statement yourself instead of only watching the examples.

### 2. SQL and Database Concepts

**Video:** [Watch on YouTube](https://www.youtube.com/watch?v=jR4fxWSmzSw)

- **Level:** Beginner
- **Focus:** Additional SQL and database explanations.
- **What you will learn:**
  - Basic SQL concepts.
  - Database terminology.
  - Query-related concepts.
  - Examples of working with databases.

**How to use it:**

Use this resource as supplementary material when you need another explanation of database concepts.

## Topics to practise after watching

Follow the database `topics.md` checklist.

Important areas may include:

- Database fundamentals.
- DBMS and RDBMS.
- Tables, records and fields.
- Primary keys and foreign keys.
- SQL commands.
- SELECT, INSERT, UPDATE and DELETE.
- WHERE, ORDER BY and GROUP BY.
- SQL joins.
- Database relationships.
- Normalisation.
- Transactions.
- Indexing.

Check your actual checklist before deciding which topics to study.

## Practice method

After learning a SQL concept:

1. Read the query.
2. Identify what it does.
3. Predict the result.
4. Execute it if a database environment is available.
5. Modify the query.
6. Solve related MCQs.

## Coverage note

The recommended videos mainly introduce SQL and relational databases.

They may not fully cover:

- Advanced normalisation.
- Transaction management.
- Indexing and query optimisation.
- Database recovery.
- Distributed databases.
- NoSQL databases.

Use `topics.md` to identify missing areas and study them separately.
