# YouTube Learning Resources: AI, Machine Learning and Data Analytics

This page provides resources for understanding introductory Artificial Intelligence, Machine Learning and related data concepts.

Focus on understanding the fundamental ideas before moving to advanced implementations.

## Recommended videos

### 1. Machine Learning with Python: Full Course

**Video:** [Watch on YouTube](https://www.youtube.com/watch?v=hDKCxebp88A)

- **Level:** Beginner to Intermediate
- **Focus:** Introduction to Machine Learning using Python.
- **What you will learn:**
  - What Machine Learning is.
  - Basic machine learning terminology.
  - How machine learning systems learn from data.
  - Common machine learning approaches.
  - Practical examples using Python.

**How to use it:**

Start with the introductory sections.

Focus on understanding the concepts and their applications. You do not need to master every programming example.

### 2. freeCodeCamp: Additional Learning Resources

**Channel:** [Visit freeCodeCamp on YouTube](https://www.youtube.com/c/Freecodecamp)

- **Level:** Beginner to Advanced
- **Focus:** Programming, Artificial Intelligence, Machine Learning and Data Analytics.
- **What you can learn:**
  - Programming fundamentals.
  - Python.
  - Machine Learning.
  - Data analysis.
  - AI-related concepts.

**How to use it:**

Search the channel for a specific topic from your `topics.md` checklist.

Choose a video that explains that topic instead of watching unrelated courses.

## Practice method

For each concept:

1. Understand what the concept means.
2. Learn a practical example.
3. Identify where it is used.
4. Compare it with related concepts.
5. Solve MCQs and scenario-based questions.

For example, understand the difference between supervised and unsupervised learning.

## Coverage note

The recommended machine learning course focuses on Python and Machine Learning.

It may not fully cover general AI concepts, statistics, data analytics or every topic in the NSCT checklist.

The freeCodeCamp channel is a collection of different courses, not one complete NSCT course.

Use `topics.md` to identify the exact areas you still need to study.
