# Programming (C++ / Java / Python) — Topic Checklist

**Published HEC weightage:** 10%

The headings follow the HEC competency areas. The bullet-level breakdowns are expanded study guidance to help you prepare; they are not a separately published official micro-syllabus.

## Programming fundamentals
- [ ] Source code, compilation and interpretation
- [ ] Program structure, statements and expressions
- [ ] Algorithms, pseudocode and basic debugging

## Data types and variables
- [ ] Identifiers, keywords, constants and variables
- [ ] Primitive types: integer, floating point, character, boolean
- [ ] Type conversion, casting and type errors
- [ ] Scope and lifetime of variables

## Operators and expressions
- [ ] Arithmetic, relational and logical operators
- [ ] Assignment, increment/decrement and compound assignment
- [ ] Operator precedence and associativity
- [ ] Bitwise operators basics
- [ ] Short-circuit evaluation

## Control structures
- [ ] if, if-else and nested conditions
- [ ] switch/match-style selection where supported
- [ ] for, while and do-while loops
- [ ] break, continue and nested loops

## Functions and methods
- [ ] Declaration, definition, parameters and return values
- [ ] Pass-by-value and reference concepts
- [ ] Local and global scope
- [ ] Recursion fundamentals
- [ ] Function overloading concepts

## Input and output
- [ ] Console input and output
- [ ] Formatted output and basic formatting
- [ ] File input/output concepts
- [ ] Input validation

## Strings and text processing
- [ ] String creation, indexing and slicing/access
- [ ] Common string operations and methods
- [ ] Concatenation, comparison and searching
- [ ] Tokenization and basic parsing

## Arrays and collections
- [ ] One-dimensional and multidimensional arrays
- [ ] Lists, vectors, ArrayLists and Python lists
- [ ] Indexing, traversal, insertion and deletion
- [ ] Sets, maps/dictionaries and key-value data
- [ ] Collection iteration

## Object-oriented programming
- [ ] Classes, objects, fields and methods
- [ ] Constructors and destructors concepts
- [ ] Encapsulation and access modifiers
- [ ] Inheritance and composition
- [ ] Polymorphism and method overriding
- [ ] Abstraction and interfaces

## Memory management
- [ ] Stack and heap concepts
- [ ] References and pointers at a conceptual level
- [ ] Dynamic allocation and deallocation concepts
- [ ] Garbage collection basics
- [ ] Common memory errors: leaks, dangling references and bounds errors

## Exceptions and errors
- [ ] Syntax, compile-time and runtime errors
- [ ] try/catch/except and finally concepts
- [ ] Throwing and handling exceptions
- [ ] Designing useful error messages

## Modules, packages and libraries
- [ ] Import/include and package concepts
- [ ] Standard libraries
- [ ] Dependency and package management basics
- [ ] Namespaces and module organization

## Advanced programming concepts
- [ ] Generics/templates concepts
- [ ] Iterators and higher-order functions
- [ ] Functional programming basics
- [ ] Callbacks and event-driven programming

## Concurrency and parallelism
- [ ] Process vs thread
- [ ] Concurrency vs parallelism
- [ ] Race conditions and critical sections
- [ ] Synchronization concepts and deadlock awareness

## Debugging, testing and optimization
- [ ] Breakpoints and step-through debugging
- [ ] Unit tests and assertions
- [ ] Test cases and edge cases
- [ ] Profiling intuition and simple optimization

## Software development practices
- [ ] Readable naming and formatting
- [ ] Comments and documentation
- [ ] Version control basics
- [ ] Code reuse and modularity
