# YouTube Learning Resources: Programming

This page contains beginner-friendly programming resources to help you understand programming fundamentals.

The resources below focus mainly on Python. The NSCT programming competency may include C++, Java and Python, so do not assume that Python videos cover every language-specific topic.

## Recommended videos

### 1. Python Tutorial: Geeky Shows

**Video:** [Watch on YouTube](https://www.youtube.com/watch?v=URfNAAuZ52w)

- **Level:** Beginner
- **Focus:** Python programming fundamentals.
- **What you will learn:**
  - Introduction to Python.
  - Variables and data types.
  - Operators.
  - Conditional statements.
  - Loops.
  - Functions and basic programming concepts.

**How to use it:**

Start from the beginning if you are new to programming.

Pause after each concept and write small programs yourself.

### 2. Python Tutorial for Beginners: CodeWithHarry

**Video:** [Watch on YouTube](https://www.youtube.com/watch?v=7wnove7K-ZQ)

- **Level:** Beginner
- **Focus:** Learning Python step by step.
- **What you will learn:**
  - Python syntax.
  - Variables and data types.
  - Conditions and loops.
  - Functions.
  - Lists and other basic structures.
  - Practical programming examples.

**How to use it:**

Use this resource when you need another explanation or more examples.

Do not just watch the video. Type the examples and predict their output before running them.

## Topics to practise after watching

Follow the programming `topics.md` checklist.

Important foundations include:

- Variables and constants.
- Data types.
- Operators.
- Input and output.
- Conditional statements.
- Loops.
- Functions.
- Arrays and strings.
- Basic object-oriented programming, where included.
- Code tracing and output prediction.

## Practice method

For every programming topic:

1. Understand the concept.
2. Read a short code example.
3. Predict the output.
4. Run the code.
5. Change the values and observe the result.
6. Solve related MCQs.

## Coverage note

These resources focus on Python. They do not provide complete coverage of C++ or Java.

If the checklist includes language-specific concepts, study those concepts separately using suitable resources.

The repository's `topics.md` file should guide your preparation, not the video playlist alone.
