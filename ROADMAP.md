# Study Roadmap

1. **Foundation:** Problem-solving logic, programming basics and basic mathematics.
2. **Core CS:** Data structures, algorithms, databases and operating systems.
3. **Engineering:** Software engineering and web development.
4. **Infrastructure:** Networks and cloud computing.
5. **Data/AI:** Analytics, machine learning and AI fundamentals.
6. **Security:** Cybersecurity and secure development.
7. **Consolidation:** Mixed MCQs, timed practice if the official format confirms timing, and revision of mistakes.

Use the published weightage to allocate effort, but do not ignore lower-weight areas.
