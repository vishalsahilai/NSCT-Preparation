# NSCT HCI Preparation Roadmap

A structured, beginner-friendly roadmap for preparing for Pakistan's National Skills Competency Test (NSCT) for IT graduates.

> **Important:** This is a suggested study plan, not an official HEC timetable. The eight-week sequence is flexible. Follow the latest instructions, eligibility requirements, test dates and exam format published on the official NSCT portal.

## How to use this roadmap

1. Start with [Getting Started](00-Getting-Started/README.md) (adjust this link if your Getting Started landing page has a different filename).
2. Review the official HEC competency areas and published weightage.
3. Complete the relevant subject's `topics.md` checklist.
4. Use the learning resources linked in the repository. Check that each external resource is accessible and covers the intended topic.
5. Practise questions after learning each topic.
6. Record weak areas in `PROGRESS-TRACKER.md` and maintain a separate mistake log.
7. Revisit difficult topics during weekly review.

## The learning cycle

Use the same cycle for every topic:

**Understand → Learn → Practise → Check → Review**

- **Understand:** Read the topic name and learning objectives. Identify what you already know.
- **Learn:** Use the recommended explanation, video, documentation or notes.
- **Practise:** Solve examples and questions without looking at the answers.
- **Check:** Review every answer and understand why incorrect options are incorrect.
- **Review:** Revisit difficult concepts after a gap and test yourself again.

## Subject areas and published weightage

Use the following published subject weightage as a guide for allocating preparation effort. It is not a reason to completely skip a lower-weight subject.

| Subject | Published weightage |
|---|---:|
| Problem Solving & Analytical Skills | 20% |
| Programming (C++/Java/Python) | 10% |
| Data Structures & Algorithms | 10% |
| Databases | 10% |
| Software Engineering | 10% |
| Web Development | 10% |
| Computer Networks & Cloud Computing | 10% |
| AI / Machine Learning & Data Analytics | 10% |
| Operating Systems | 5% |
| Cyber Security | 5% |
| **Total** | **100%** |

Always re-check the official portal for the current published competency areas and weightage.

# Eight-week preparation plan

The plan below gives each week a focus, concrete tasks and an end-of-week checkpoint. It does not assume a fixed number of study hours per day. Adjust the pace to your available time and current knowledge.

## Week 1 — Orientation, diagnostic assessment and foundations

**Main goal:** Understand the test scope and establish your starting level.

### Tasks
- Read the repository README and Getting Started material.
- Review the official NSCT portal and published competency areas.
- Open all 10 subject folders and review their `topics.md` checklists.
- Attempt a small diagnostic set from each subject, if practice questions are available.
- Mark each topic as: Not Started, Learning, Needs Practice or Reviewed.
- Begin Problem Solving & Analytical Skills.
- Review basic mathematical reasoning, patterns, logical reasoning and analytical thinking where included in the subject checklist.

### End-of-week checkpoint
- You can explain the purpose of the test and identify all subject areas.
- You have a baseline record of stronger and weaker subjects.
- You have started a consistent mistake log.

## Week 2 — Problem Solving and Programming

**Main goal:** Build reasoning skills and strengthen programming fundamentals.

### Tasks
- Continue the Problem Solving checklist.
- Practise logical reasoning, analytical questions, algorithms, flowcharts and other listed topics.
- Study Programming fundamentals using the language and topics in the repository.
- Practise variables, data types, operators, conditions, loops, functions and basic problem-solving where included in the checklist.
- Trace code manually and predict outputs before checking them.
- Solve topic-wise questions after each learning session.

### End-of-week checkpoint
- You can explain the main problem-solving methods you studied.
- You can trace basic code and identify common logic errors.
- You have reviewed and recorded your incorrect answers.

## Week 3 — Data Structures, Algorithms and Databases

**Main goal:** Understand how data is organised, processed and stored.

### Tasks
- Study the Data Structures & Algorithms checklist.
- Learn each listed structure and algorithm from its basic idea before attempting complex questions.
- Trace examples by hand and compare alternative approaches.
- Study database fundamentals and the database topics listed in the repository.
- Practise query reading, data modelling and database concepts where applicable.
- Complete topic-wise MCQs or exercises after each topic.

### End-of-week checkpoint
- You can describe the purpose and basic operation of the structures and algorithms studied.
- You can explain core database concepts and interpret the queries covered.
- You can identify topics that need another revision session.

## Week 4 — Software Engineering and Web Development

**Main goal:** Understand the software development process and web fundamentals.

### Tasks
- Follow the Software Engineering topic checklist.
- Study the listed development models, requirements, design, testing and maintenance concepts.
- Compare similar terms and understand when each concept is used.
- Follow the Web Development checklist.
- Study the web concepts, technologies and protocols included in the repository.
- Practise scenario-based questions, not only definition-based questions.

### End-of-week checkpoint
- You can distinguish important software engineering concepts.
- You can explain the web technologies and concepts covered in your checklist.
- You have completed practice for the topics studied.

## Week 5 — Networks, Cloud Computing and Operating Systems

**Main goal:** Understand computer infrastructure and operating-system fundamentals.

### Tasks
- Study the Networks & Cloud Computing checklist.
- Review networking concepts, models, protocols and cloud concepts included in the repository.
- Use diagrams to understand how components communicate.
- Study the Operating Systems checklist.
- Review processes, threads, memory, scheduling, file systems and other listed concepts.
- Practise questions that ask you to apply concepts to a situation.

### End-of-week checkpoint
- You can explain the networking and cloud concepts covered.
- You can distinguish the operating-system concepts studied.
- You have recorded any confusing terms for revision.

## Week 6 — AI, Machine Learning, Data Analytics and Cybersecurity

**Main goal:** Cover the remaining subject areas and connect the concepts to practical examples.

### Tasks
- Follow the AI / ML & Data Analytics checklist.
- Study the basic concepts, terminology, methods and use cases listed there.
- Distinguish AI, machine learning, deep learning and data analytics where covered.
- Follow the Cyber Security checklist.
- Review security principles, threats, vulnerabilities, controls and safe practices included in the repository.
- Practise concept and scenario-based questions.
- Revisit any unfinished topics from earlier weeks.

### End-of-week checkpoint
- You can explain the main concepts from AI, ML, data analytics and cybersecurity.
- You have attempted practice questions from both subject areas.
- Every subject has been started, and unfinished topics are clearly recorded.

## Week 7 — Consolidation and subject-wise testing

**Main goal:** Turn topic knowledge into reliable question-solving ability.

### Tasks
- Review all 10 subject checklists.
- Complete unfinished high-priority topics, while keeping lower-weight subjects in the revision cycle.
- Attempt subject-wise practice sets.
- Mix questions from different topics to check whether you can identify the correct concept without a topic label.
- Review every wrong or guessed answer.
- Re-study concepts responsible for repeated mistakes.
- Use timed practice only if the official test format confirms a time limit, or clearly label it as a self-imposed practice exercise.

### End-of-week checkpoint
- You have attempted practice across all 10 subjects.
- Your mistake log shows the concepts that still need attention.
- You have a short revision list for the final week.

## Week 8 — Final revision and mock-test practice

**Main goal:** Consolidate knowledge and prepare calmly for the test.

### Tasks
- Revise summaries, definitions, formulas, diagrams and important distinctions from your notes.
- Revisit weak topics identified in the tracker and mistake log.
- Attempt available full-length or mixed mock tests.
- Follow the official exam format when it is published and verified.
- Analyse mock-test mistakes instead of only recording a score.
- Avoid spending all your time on familiar topics; check that every subject receives revision.
- Confirm test date, venue or online arrangements, required documents and instructions through official channels.

### End-of-week checkpoint
- You have revised all subject areas.
- You have reviewed repeated mistakes.
- You understand the official test instructions and are ready for the test.

## Suggested weekly routine

Repeat this routine during each week. Change the amount of time spent according to your schedule and topic difficulty.

| Session | What to do |
|---|---|
| Start | Review the previous session's notes and mistakes. |
| Learn | Study one small topic using the linked material. |
| Apply | Work through examples or trace a process by hand. |
| Practise | Solve questions without checking answers first. |
| Review | Explain mistakes and update the progress tracker. |

## How to prioritise your work

Use three factors together:

1. **Published weightage:** Give proportionate attention to higher-weight subjects.
2. **Your current level:** Spend additional time on topics you do not understand.
3. **Topic importance and prerequisites:** Learn foundational concepts before dependent topics.

Do not interpret the suggested eight-week order as an official exam sequence. The order is a learning path designed to move from foundations toward application and revision.

## If you have less or more than eight weeks

- **Less time:** Keep the same learning cycle, shorten the time spent on familiar topics, and prioritise unfinished foundations and weak areas. Do not assume any subject can safely be skipped.
- **More time:** Expand each week, add more topic-level practice, and repeat subject-wise assessments.
- **Already strong in a subject:** Use a diagnostic set to identify gaps, then focus on weak topics instead of repeating everything equally.
