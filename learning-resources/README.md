# Learning Resources

Welcome to the NSCT Preparation learning resources.

This section helps you find useful external learning material for each subject.

Instead of keeping every video in one central file, each subject folder contains its own `YOUTUBE.md` file.

This makes it easier to find resources related to the topic you are currently studying.

## How to use these resources

Follow this learning sequence:

1. Open the relevant subject folder.
2. Read its `topics.md` checklist.
3. Open its `YOUTUBE.md` file.
4. Select a video that matches the topic you are studying.
5. Watch the relevant section.
6. Practise questions related to that topic.
7. Update your progress tracker.

## Important resource guidelines

- Videos are supplementary learning resources, not official NSCT material.
- Always compare video content with the subject's `topics.md` checklist.
- A video may explain only some parts of a subject.
- Do not assume that watching a complete video means you have completed the entire subject.
- If a link is unavailable, find a replacement that covers the same topic.
- Prefer clear explanations with practical examples.
- Practise MCQs after learning each topic.
