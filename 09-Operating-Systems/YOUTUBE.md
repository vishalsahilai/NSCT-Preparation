# YouTube Learning Resources: Operating Systems

This page provides video resources for understanding Operating System fundamentals.

Start with the basic purpose and responsibilities of an operating system before studying processes, memory and scheduling.

## Recommended videos

- **Level:** Beginner to Intermediate
- **Focus:** Operating System fundamentals.
- **What you can learn:**
  - Introduction to Operating Systems.
  - Operating System functions.

  - Important theoretical topics.

## Topics to practise after watching

Follow the Operating Systems `topics.md` checklist.

Common areas include:

- Introduction to Operating Systems.
- Types of Operating Systems.
- Processes and threads.
- Process scheduling.
- CPU scheduling algorithms.
- Memory management.
- Virtual memory.
- Paging and segmentation.
- Deadlocks.
- File systems.
- Synchronisation.

## Practice method

For every topic:

1. Understand its purpose.
2. Learn the main definitions.
3. Draw diagrams where useful.
4. Trace examples manually.
5. Compare similar concepts.
6. Solve related MCQs.

For CPU scheduling, practise calculating waiting time and turnaround time if those topics are included in your checklist.

## Coverage note

These videos provide introductory and theoretical OS material.

They may not cover every topic or calculation required by your checklist.

Use `topics.md` to identify missing concepts and find additional explanations where needed.
