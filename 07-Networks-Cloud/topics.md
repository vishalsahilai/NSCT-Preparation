# Computer Networks & Cloud Computing — Topic Checklist

**Published HEC weightage:** 10%

The headings follow the HEC competency areas. The bullet-level breakdowns are expanded study guidance to help you prepare; they are not a separately published official micro-syllabus.

## Data communication
- [ ] Components of data communication
- [ ] Bandwidth, throughput, latency and jitter
- [ ] Transmission modes and media
- [ ] Analog vs digital and signal basics

## Network foundations
- [ ] LAN, MAN, WAN and PAN
- [ ] Network topologies
- [ ] OSI and TCP/IP models
- [ ] Encapsulation and decapsulation
- [ ] Network devices: hub, switch, router, gateway

## Data link layer
- [ ] Framing and MAC addressing
- [ ] Error detection: parity, checksum and CRC
- [ ] Flow control basics
- [ ] Ethernet and switching
- [ ] VLAN concepts

## Network layer
- [ ] IPv4 addressing and subnetting
- [ ] Private vs public IP addresses
- [ ] CIDR and subnet masks
- [ ] IPv6 basics
- [ ] Routing and routing tables
- [ ] ARP, ICMP and NAT

## Transport layer
- [ ] TCP vs UDP
- [ ] Ports and sockets
- [ ] Three-way handshake and connection termination
- [ ] Reliability, flow control and congestion control

## Application layer
- [ ] DNS, DHCP and HTTP/HTTPS
- [ ] FTP/SFTP and email protocols
- [ ] SMTP, POP3 and IMAP
- [ ] SSH and remote access

## Wireless networks
- [ ] Wi-Fi standards overview
- [ ] Access points and wireless security
- [ ] Bluetooth and cellular basics
- [ ] Wireless interference and roaming

## Cloud computing
- [ ] Cloud characteristics and service models: IaaS, PaaS, SaaS
- [ ] Public, private, hybrid and community cloud
- [ ] Virtualization and containers
- [ ] Compute, storage and networking services
- [ ] Scalability, elasticity and availability
- [ ] Shared responsibility model

## Network security
- [ ] Firewalls and network segmentation
- [ ] VPNs and secure tunnels
- [ ] IDS vs IPS
- [ ] TLS and secure communication
- [ ] DDoS concepts and mitigation

## Next-generation networks
- [ ] Software-defined networking (SDN)
- [ ] Network function virtualization (NFV)
- [ ] 5G and edge computing overview
- [ ] IoT networking concepts
