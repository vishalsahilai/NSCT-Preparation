# YouTube Learning Resources: Computer Networks and Cloud Computing

This page provides resources for understanding networking fundamentals and introductory cloud computing concepts.

Start with basic networking terminology before studying more complex topics.

## Recommended videos

### 1. NetworkChuck: Networking Learning Resources

**Channel and playlists:** [Visit NetworkChuck on YouTube](https://www.youtube.com/@NetworkChuck/playlists)

- **Level:** Beginner to Intermediate
- **Focus:** Networking and related technology concepts.
- **What you can learn:**
  - Networking fundamentals.
  - IP addresses.
  - Network devices.
  - Basic network configuration.
  - Practical networking concepts.

**How to use it:**

Open the channel playlists and select videos that match the topics in your checklist.

Use practical demonstrations to understand how networking concepts work.

- Cloud service models.
- Cloud deployment models.

## Practice method

For networking concepts:

1. Learn the definition.
2. Understand the purpose.
3. Draw a diagram.
4. Compare similar technologies.
5. Solve scenario-based questions.

For example, understand the difference between TCP and UDP instead of memorising only their names.
