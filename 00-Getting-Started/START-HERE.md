# Start Here

- [ ] Confirm the latest candidate instructions on the [official NSCT portal](https://nsct.hec.gov.pk/).
- [ ] Read the [official Areas of Competencies](https://nsct.hec.gov.pk/AreasOfCompetencies).
- [ ] Start with Problem Solving (20%), then cover the seven 10% areas, then OS and Cyber Security (5% each).
- [ ] Open each subject's `topics.md`; tick topics only after you can explain and apply them.
- [ ] Use videos as learning support, not as proof that every HEC topic is covered.
- [ ] Practice MCQs and code-tracing, then record mistakes in `12-Revision/MISTAKE-LOG.md`.
