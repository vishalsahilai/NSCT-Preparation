# YouTube Learning Resources: Getting Started

This page helps you understand how to use the NSCT Preparation repository and organise your study.

## Recommended learning approach

There is no need to watch random videos before understanding the test structure.

Follow this sequence:

1. Read the main repository `README.md`.
2. Review the `ROADMAP.md`.
3. Open each subject folder.
4. Read that subject's `topics.md`.
5. Use the relevant `YOUTUBE.md` to find video explanations.
6. Practise questions after learning each topic.
7. Update `PROGRESS-TRACKER.md`.
