# Problem Solving & Analytical Skills — Topic Checklist

**Published HEC weightage:** 20%

The headings follow the HEC competency areas. The bullet-level breakdowns are expanded study guidance to help you prepare; they are not a separately published official micro-syllabus.

## Problem-solving foundations
- [ ] Define a problem; identify inputs, outputs, constraints and goals
- [ ] Decompose a complex problem into smaller tasks
- [ ] Abstraction, modeling and assumptions
- [ ] Understand functional and non-functional requirements

## Problem analysis
- [ ] Identify relevant and irrelevant information
- [ ] Represent a problem using tables, diagrams, pseudocode and examples
- [ ] Identify edge cases and boundary conditions
- [ ] Trace cause-and-effect relationships

## Logical reasoning
- [ ] Propositions, truth values and logical operators
- [ ] AND, OR, NOT, XOR and implication
- [ ] Truth tables and equivalent statements
- [ ] Deductive, inductive and conditional reasoning
- [ ] Syllogisms, sequences and logical puzzles

## Algorithms and flow control
- [ ] Algorithm properties: correctness, finiteness and definiteness
- [ ] Pseudocode and flowcharts
- [ ] Sequence, selection and iteration
- [ ] Nested conditions and loops
- [ ] Dry-running and tracing algorithms

## Data representation and abstraction
- [ ] Binary, decimal and hexadecimal basics
- [ ] Bits, bytes and simple data representation
- [ ] Variables, constants, data types and state
- [ ] Tables, sets, lists and simple models

## Patterns and generalization
- [ ] Number and character patterns
- [ ] Recognize repetition and invariants
- [ ] Generalize from examples
- [ ] Use pattern recognition to simplify a problem

## Mathematical and quantitative reasoning
- [ ] Arithmetic, fractions, ratios and percentages
- [ ] Averages, proportions and rates
- [ ] Exponents, roots and logarithm basics
- [ ] Number properties and divisibility
- [ ] Basic counting and probability
- [ ] Interpret charts, tables and simple statistics

## Algorithmic thinking
- [ ] Stepwise refinement
- [ ] Greedy choice intuition and exhaustive search
- [ ] Recursion intuition
- [ ] Break problems into reusable procedures
- [ ] Select suitable data representations

## Critical thinking and decisions
- [ ] Compare alternative solutions
- [ ] Evaluate evidence and assumptions
- [ ] Trade-offs: time, space, cost and accuracy
- [ ] Decision tables and simple scenario analysis

## Debugging and error analysis
- [ ] Syntax, runtime and logic errors
- [ ] Trace values to locate a fault
- [ ] Test with normal, boundary and invalid inputs
- [ ] Use counterexamples to disprove a solution

## Complexity awareness
- [ ] Understand growth of input size
- [ ] Recognize constant, linear, quadratic and logarithmic growth
- [ ] Compare simple approaches by time and memory
- [ ] Best, average and worst-case intuition

## Programming-based problem solving
- [ ] Translate a written problem into code steps
- [ ] Read and trace short code snippets
- [ ] Use variables, conditions, loops and functions
- [ ] Validate output against expected results

## Data-driven problem solving
- [ ] Read and interpret datasets
- [ ] Identify missing, duplicate and inconsistent data
- [ ] Use summaries and simple comparisons
- [ ] Draw cautious conclusions from data

## Creative and real-world problem solving
- [ ] Generate multiple solution ideas
- [ ] Choose a practical solution under constraints
- [ ] Model everyday and business scenarios
- [ ] Document the solution and communicate limitations
