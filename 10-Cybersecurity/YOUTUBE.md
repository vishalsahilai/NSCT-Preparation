# YouTube Learning Resources: Cybersecurity

This page provides introductory resources for understanding cybersecurity, network security and basic security practices.

Focus on defensive security concepts and authorised learning.

## Recommended videos

### 1. Google: Network Security

**Video:** [Watch on YouTube](https://www.youtube.com/watch?v=NqgqJj9bpWc)

- **Level:** Beginner
- **Focus:** Introduction to network security.
- **What you can learn:**
  - Basic network security concepts.
  - Why network security matters.
  - Common security principles.
  - How organisations protect networks.

**How to use it:**

Watch the video to understand the purpose of network security.

Write short notes about the important security concepts.

- **What you can learn:**

## Topics to practise after watching

Follow the Cybersecurity `topics.md` checklist.

Common areas include:

- Cybersecurity fundamentals.
- Confidentiality, Integrity and Availability (CIA triad).
- Authentication and authorisation.
- Encryption and decryption.
- Malware.
- Phishing and social engineering.
- Firewalls.
- Network security.
- Vulnerabilities and threats.
- Access control.
- Security best practices.

## Practice method

For every security concept:

1. Understand the meaning.
2. Identify the security problem it addresses.
3. Learn a practical example.
4. Compare it with similar concepts.
5. Solve related MCQs.

For example, understand the difference between authentication and authorisation.

## Coverage note

The recommended videos are introductory resources.

They may not fully cover cryptography, security protocols, access control, risk management or every topic in the NSCT checklist.

Use `topics.md` to identify additional areas that require study.
