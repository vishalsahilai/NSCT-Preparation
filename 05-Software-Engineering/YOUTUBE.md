# YouTube Learning Resources: Software Engineering

Software Engineering covers the processes and techniques used to design, develop, test and maintain software systems.

These resources help you understand important concepts and software development practices.

## Recommended videos

### 1. System Design and Software Architecture

**Video:** [Watch on YouTube](https://www.youtube.com/watch?v=C842vFY5kRo)

- **Level:** Beginner to Intermediate
- **Focus:** System design and software architecture concepts.
- **What you will learn:**
  - Introduction to system design.
  - Software architecture concepts.
  - How software components interact.
  - Design considerations.
  - High-level system organisation.

**How to use it:**

Use this resource to understand how software systems are structured.

Focus on the basic ideas rather than advanced architecture details.

### 2. Gate Smashers: Software Engineering Playlist

**Playlist:** [Watch on YouTube](https://www.youtube.com/@GateSmashers/playlists)

- **Level:** Beginner to Intermediate
- **Focus:** Computer science and software engineering topics.
- **What you can study:**
  - Software Engineering fundamentals.
  - Software development concepts.
  - Related theoretical computer science topics.

**How to use it:**

Open the channel's playlists and select videos that match your `topics.md` checklist.

Do not watch every playlist without checking whether it is relevant.

## Topics to practise after watching

Follow the Software Engineering `topics.md` checklist.

Common areas include:

- Software development life cycle.
- Software process models.
- Waterfall model.
- Agile development.
- Requirements engineering.
- Software design.
- Software testing.
- Verification and validation.
- Software maintenance.
- Software quality.

## Practice method

For every concept:

1. Understand its purpose.
2. Learn its main characteristics.
3. Compare it with similar concepts.
4. Study a practical scenario.
5. Solve related MCQs.

For example, do not only memorise the names of development models. Understand when each model is suitable.

## Coverage note

The system design video is not a complete Software Engineering course.

The Gate Smashers channel contains multiple subjects, so select only the videos relevant to the repository's checklist.

Use `topics.md` as the final guide for syllabus coverage.
